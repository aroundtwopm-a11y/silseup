# docs-one-pager

docs 폴더의 기준 문서를 모두 읽고, 팀에 공유할 1장짜리 요약(핵심 기능·화면)을 만든다.

## 작업 순서

1. **파일 목록과 원본 상태 기록**: `docs/` 아래 모든 파일(하위 폴더 포함)을 나열하고, 각 파일의 크기와 수정 시각을 적어 둔다. 이 목록이 완료 확인의 기준이 된다.

   ```powershell
   Get-ChildItem docs -Recurse -File | Select-Object FullName, Length, LastWriteTime
   ```

   - docs 폴더가 없거나 파일이 하나도 없으면 **여기서 멈추고** 사용자에게 알린다. 빈 요약을 만들지 않는다.
   - 텍스트가 아닌 파일(이미지, PDF 등)은 읽지 않고 목록에만 남긴다.
2. **중요도 순으로 읽기**: PRD → DOMAIN → screens → design → token → 나머지(가나다 순). 파일명에 해당 단어가 들어가면 그 순서로 본다.
   - 긴 파일은 잘리지 않도록 끝까지 나눠 읽는다(offset/limit 사용). 중간까지만 읽고 넘어가지 않는다.
3. **문서별 핵심 3줄 메모**: 문서 하나를 읽을 때마다 핵심 3줄을 메모한다(작업용, 파일로 저장하지 않음). 요약에 반영할 내용이 없는 문서는 "반영할 내용 없음"으로 메모한다.
4. **요약 작성**: 메모를 합쳐 아래 형식으로 "핵심 기능·화면"을 정리한다.
   - **핵심 기능은 최대 8개, 주요 화면은 최대 10개**.
   - PRD에서 핵심·필수·우선순위가 높다고 표시된 것부터 넣는다. 표시가 없으면 여러 문서에 반복해서 나오는 것을 먼저 넣는다.
   - 개수를 넘는 나머지는 마지막 줄에 `- 외 N개 (출처: 파일명)`으로 한 줄 처리한다.
   - 프로젝트명은 PRD에서 가져오고, 없으면 `(확인 필요)`로 쓴다. 날짜는 실행한 날로 쓴다.
5. **저장**: 프로젝트 루트에 `ONE-PAGER.md`로 저장한다. 이미 있으면 덮어쓰기 전에 사용자에게 먼저 묻는다.
6. **완료 확인**: 아래 체크리스트를 실제로 확인한 뒤 보고한다.

## 결과 파일 형식

- 파일: 프로젝트 루트 `ONE-PAGER.md` (Markdown)
- 분량: **전체 30줄 이내** (제목·빈 줄·주석 포함)
- 구성:

```markdown
# <프로젝트명> 핵심 기능·화면 (YYYY-MM-DD 기준)

## 핵심 기능
- <기능 설명> (출처: PRD.md)
- ...

## 주요 화면
- <화면명>: <한 줄 설명> (출처: screens.md.txt)
- ...

<!-- 기준 문서: docs/의 파일 N개 | 읽었지만 반영할 내용 없음: <파일명>, ... | 읽지 않은 비텍스트 파일: <파일명>, ... -->
```

해당 내용이 없는 항목은 주석에서 뺀다.

## 꼭 지킬 것

- **지어내지 않기**: 기준 문서에 없는 내용은 쓰지 않는다. 불분명하거나 문서끼리 다르면 해당 줄 끝에 `(확인 필요)`라고 표시한다.
- **docs 원본 수정 금지**: docs 폴더는 읽기만 한다. 쓰는 파일은 `ONE-PAGER.md` 하나뿐이다.
- **고객 개인정보(PII) 제외**: 이름, 연락처, 이메일, 계정, 주소 등 고객 개인정보는 문서에 있어도 넣지 않는다.
- **덮어쓰기 전 확인**: `ONE-PAGER.md`가 이미 있으면 사용자에게 묻고 승인받은 뒤 덮어쓴다.

## 끝났는지 확인 (모두 통과해야 완료)

- [ ] 1단계 파일 목록의 텍스트 파일을 모두 끝까지 읽었다 (읽은 목록과 대조)
- [ ] `ONE-PAGER.md`가 30줄 이내다. 저장 후 실제로 센다:

  ```powershell
  (Get-Content ONE-PAGER.md).Count
  ```

- [ ] 기능 8개·화면 10개 이내이고, 항목마다 `(출처: 파일명)`이 있다
- [ ] 고객 개인정보가 없다
- [ ] docs 폴더가 바뀌지 않았다: 1단계 명령을 다시 실행해 파일 수·크기·수정 시각이 처음과 같은지 비교한다

하나라도 실패하면 고쳐서 다시 확인한다.

## 보고

끝나면 사용자에게 다음을 알린다.

- `ONE-PAGER.md` 파일 링크
- 읽은 문서 수 / docs 전체 파일 수
- 줄 수
- `(확인 필요)` 항목 수
- 체크리스트 통과 결과
