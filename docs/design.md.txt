# Design.md

이 문서는 현재 파일의 변수, 로컬 텍스트 스타일, Components 섹션의 컴포넌트 정의를 기준으로 작성했다.

- 단위는 별도 표기가 없으면 px이다.
- 색상은 semantic 변수의 별칭을 실제 색상으로 해석한 값이다.
- 토큰은 `컬렉션/변수 이름`으로 표기한다.
- 디자인 토큰 컬렉션은 모두 `Default` 단일 모드이며, 별도의 다크 모드는 없다.
- 용도는 실제 컴포넌트 연결과 설명을 우선하며, 별도 정의가 없는 항목은 토큰 역할에 따른 권장 용도로 구분한다.

색상 적용 시 유의사항:

- `bg/surface`와 `surface/default`는 현재 값이 같지만 서로 다른 토큰이다.
- `fill/accent`는 `#E6007E`, `text/accent`와 `icon/accent`는 `#FF2E98`이다.
- 선택된 카드의 외곽선은 분홍색이 아니라 `border/medium`이다.
- primitive의 `pink/25 = #FFF8F5`는 존재하지만 현재 semantic 별칭에는 연결되어 있지 않다.

## 2. 타이포 스케일

- 기본 글꼴: Noto Sans KR
- 글꼴 변수: `typography/font-family/family-font`
- 모든 로컬 텍스트 스타일의 자간: 0%
- Medium = 500, SemiBold = 600, Bold = 700
- 아래 크기와 줄높이는 로컬 텍스트 스타일의 실제 정의다.

| 텍스트 스타일 | 크기 / 줄높이 | 굵기 | 쓰는 곳 |
| --- | --- | --- | --- |

| heading/h2 | 28 / 40 | Bold 700 | 주요 화면 제목 권장 |
| heading/h3 | 24 / 32 | Bold 700 | 큰 섹션 제목 권장 |

적용 규칙:

- 텍스트는 크기 변수만 조합하기보다 줄높이와 굵기를 포함한 텍스트 스타일을 우선 사용한다.
- `specimen/*`은 제품 화면용 스케일이 아니라 굵기 비교용이다.
- OptionItem은 선택 시 제목이 `body/strong`에서 `subtitle/bold`로 바뀐다. 선택 전후 높이가 같다고 가정하지 않는다.
- Input 기본 상태의 숨겨진 메시지에는 `heading/h4`가 연결되어 있다. 다른 상태의 메시지는 주로 `body/small-medium`이므로 공통 메시지 스타일이 완전히 통일된 상태는 아니다.

## 3. 간격·레이아웃

### 390×844 모바일 기준

| 항목 | 확인된 값 | 적용 기준 |
| --- | --- | --- |
| 화면 기준 크기 | 390 × 844 | 세로형 모바일 |
| Header | 390 × 56 | 화면 상단 전체 너비 |
| 기본 좌우 여백 | 16 | 공통 컴포넌트 기준 |
| 기본 콘텐츠 너비 | 358 | 390 − 16 × 2 |
| 넓은 좌우 여백 | 24 | 일부 소개·상세 화면 본문과 하단 동작 영역 |
| 넓은 여백 적용 시 너비 | 342 | 390 − 24 × 2 |
| 본문 상단·하단 패딩 | 16 또는 24 | 화면별 실제 예시에 두 값이 사용됨 |
| 본문 주요 요소 간격 | 16 또는 24 | 목록·섹션 구성에 따라 구분 |
| BottomCTA 하단 여백 | 32 | 컴포넌트 설명상 홈 인디케이터 공간 |
| BottomCTA single·double 높이 | 97 | 현재 컴포넌트 외곽 실측 |
| BottomCTA price 높이 | 139 | 현재 컴포넌트 외곽 실측 |

레이아웃 규칙:

- 화면은 상단 Header, 세로 본문, 필요한 경우 하단 동작 영역으로 구성한다.
- Header와 BottomCTA는 화면 전체 너비를 사용한다.
- 본문 안의 카드·입력·선택지는 부모의 좌우 패딩을 제외한 너비에 맞춘다.
- 16px 여백과 24px 여백은 모두 실제 사용되므로 모든 화면을 한 값으로 단정하지 않는다.
- 콘텐츠가 길어지는 화면은 세로 스크롤을 전제로 구성하는 것을 권장한다.
- 하단 동작을 고정할 때는 마지막 본문 내용이 가려지지 않도록 해당 영역 높이만큼 공간을 확보한다.
- 실제 예시에는 버튼 2개를 세로로 쌓은 별도 하단 영역도 있다. 이는 BottomCTA의 가로형 `Layout=double`과 다르다.
- 별도의 상태 표시줄 높이나 추가 반응형 브레이크포인트는 확인된 정의에 포함되지 않는다.

### 간격 토큰

컬렉션 이름은 `spacing`, 변수 이름은 `spacing/N`이다.
따라서 전체 표기는 `spacing/spacing/N`이다.

등록 값:

`0, 2, 4, 6, 8, 10, 12, 16, 20, 24, 28, 32, 40, 48, 56, 60, 64, 80`

| 값 | 확인된 사용 예 또는 권장 역할 |
| --- | --- |
| 0 | 불필요한 내부 간격 제거 |
| 2, 4, 6 | 작은 내부 여백, 미세한 간격 |
| 8 | 카드 내부 간격, 버튼 사이 간격, 진행 라벨과 트랙 사이 |
| 10 | sale Chip 좌우 패딩 |
| 12 | Input과 메시지 사이, OptionItem 내부 간격, 정보 행 간격 |
| 16 | 기본 화면 좌우 여백, 본문 패딩 |
| 20 | Card/Plan 패딩, OptionItem 좌우 패딩 |
| 24 | 넓은 화면 여백, 주요 섹션 간격, 버튼 좌우 패딩 |
| 32 | BottomCTA 하단 여백 |
| 28, 40, 48, 56, 60, 64, 80 | 추가 공간 스케일. 이름만으로 특정 레이아웃 용도가 고정되지는 않음 |

## 4. 컴포넌트 용법

대상은 Components 섹션 내부의 12개 컴포넌트 세트와 5개 단독 컴포넌트다. 다른 위치의 동명 컴포넌트는 포함하지 않는다.

속성 이름 뒤의 Figma 내부 식별 접미사는 생략했다. 대소문자는 실제 정의를 유지한다.

### Button

변형:

| 속성 | 값 | 기본값 |
| --- | --- | --- |
| Type | Primary, Secondary | Primary |
| Size | sm, lg, xl | xl |
| State | Default, Hover, Disabled | Default |
| Label | 텍스트 | 로그인 |

총 18개 조합이 정의되어 있다.

크기:

| Size | 높이 | 좌우 패딩 | 상하 패딩 |
| --- | --- | --- | --- |
| sm | 주로 40 | 24 | 8 |
| lg | 48 | 24 | 12 |
| xl | 52 | 24 | 16 |

- Secondary의 sm Default·Hover는 실제 외곽 높이가 42이며 Disabled는 40이다.
- xl은 실제 높이 52를 기준으로 한다. 패딩과 글자 줄높이의 단순 합으로 높이를 다시 계산하지 않는다.
- 반경은 8이다.
- 기본 라벨은 `body/strong`이다.
- Primary Disabled 라벨은 `body/medium`이다.

상태 표현:

| 변형 | 배경 | 글자 | 테두리 |
| --- | --- | --- | --- |
| Primary / Default | fill/primary | text/on-dark | 없음 |
| Primary / Hover | fill/primary-hover | text/on-dark | 없음 |
| Secondary / Default | surface/default | text/primary | border/default |
| Secondary / Hover | bg/subtle | text/primary | border/default |
| Disabled | fill/disabled | text/on-dark | 없음 |

사용 규칙:

- 주요 진행 동작은 Primary, 보조 동작은 Secondary를 권장한다.
- 하단 주요 동작에는 xl을 사용한다.
- 라벨은 Label 속성으로 바꾼다.
- Disabled 변형은 시각 상태다. 실제 동작 차단은 별도로 연결해야 한다.

### Input

| 속성 | 값 | 기본값 |
| --- | --- | --- |
| State | default, focus, filled, caution, disabled | default |
| errorMessage | Boolean | false |

- 기본 필드 크기: 358 × 58
- caution 전체 높이: 91
- 필드와 메시지 사이 간격: 12
- 모서리: 0
- 박스형 테두리보다 하단 선 중심의 입력 표현이다.
- 입력 값과 메시지를 바꾸는 별도 TEXT 속성은 없다. 내부 텍스트를 오버라이드한다.

상태 규칙:

- default: placeholder 색상과 기본 입력선
- focus: `border/focus`
- filled: 입력 값을 `text/primary`로 표시
- caution: `border/error`, 오류 아이콘, `text/error` 메시지
- disabled: `bg/subtle`, `text/on-disabled`

주의:

- 일반 상태의 메시지 표시 여부는 errorMessage에 연결되어 있다.
- caution의 메시지는 표시된 상태이며 errorMessage 속성에 직접 연결되어 있지 않다.
- 따라서 errorMessage만으로 모든 상태의 메시지 표시를 일괄 제어할 수 있다고 가정하지 않는다.

### Checkbox

| 속성 | 값 | 기본값 |
| --- | --- | --- |
| State | default, active | default |

- 외곽 크기: 24 × 24
- 내부 주요 도형 크기: 20 × 20
- 선택 여부는 State로 표현한다.
- 별도 라벨 속성이나 Disabled 변형은 없다.
- 동의 항목에 사용할 때는 설명 텍스트와 함께 배치하는 것을 권장한다.
- 실제 체크 전환 동작은 별도로 연결한다.

### Chip

| 속성 | 값 | 기본값 |
| --- | --- | --- |
| Type | benefit, package, sale | sale |

### Card/Plan

| Discount | 텍스트 | 15% |
| Price | 텍스트 | 월 85,000원 |

- 기본 테두리: `border/default`, 1
- 선택 테두리: `border/medium`, 1.5

사용 규칙:

- Name·Desc·Price는 요금제 기본 정보다.
- Sale은 할인율과 정가 표시를 제어한다.
- Promo는 프로모션 Chip 표시를 제어한다.
- 선택 상태의 내부 버튼 기본 라벨은 선택됨이다.
- 이름·가격·할인율에는 `subtitle/bold`, 설명에는 `body/small-medium`, 정가에는 `caption/medium`이 적용된다.
- 버튼은 내부 Button 속성으로 설정한다.

현재 정의의 주의사항:

- 설명에는 Sale·Promo·Badge를 끄면 기본형 카드가 된다고 적혀 있다.
- 실제 Badge 속성은 배지의 표시 여부에 연결되어 있지 않다.
- 따라서 Badge=false만으로 배지가 숨겨진다고 가정하지 않는다.
- 선택된 카드의 외곽선은 분홍색이 아니라 회색 계열이다.

### FilterChip

| 속성 | 값 | 기본값 |
| --- | --- | --- |
| State | default, selected | default |
| Label | 텍스트 | 데이터 많이 |

- 패딩: 상하 8, 좌우 16
- 반경: 9999

사용 규칙:

- 선택 상태는 회색조로 표현한다.
- 할인·혜택을 알리는 비선택형 정보에는 Chip을 사용한다.

### 공통 적용 규칙

- 메인 정의를 화면마다 복제해 수정하기보다 인스턴스를 사용한다.
- 공개된 텍스트·Boolean·변형 속성을 우선 사용한다.
- 공개 속성이 없는 문구는 인스턴스 내부 텍스트 오버라이드로 변경한다.
- State·Step 같은 변형은 시각 상태 정의이며 실제 선택 전환·검증·탐색 동작을 자동으로 보장하지 않는다.
- 선택 상태와 표시되는 데이터가 서로 일치하도록 화면에서 상태를 관리한다.
- `요금제 신청 · 프로토타입 상태` 컬렉션의 plan/*, option/* 문자열 변수는 화면 데이터와 선택 상태용이며 색상·타이포·간격 토큰과 구분한다.
