## 01 요금제 추천

### 목적
사용자가 추천 요금제를 비교하고 상세 내용을 확인할 요금제를 선택한다.

### 라우트
/plans
- 제안 경로

### 구성 요소
- Header / Type=root / 화면 제목 "요금제 추천".
  - 내부 컴포넌트: Logo.
- 신규: 화면 안내 문구
  - "나에게 맞는 요금제를 선택해 주세요"
  - "카드를 누르면 상세 내용을 확인할 수 있어요."
- 신규: 추천 요금제 섹션 제목
  - "추천 요금제"
- Card/Plan / State=default / 추천 요금제 3개.
  - 데이터 5GB: 데이터 5GB · 통화 100분 · 문자 100건 / 월 15,000원.
  - 데이터 10GB: 데이터 10GB · 통화 무제한 · 문자 무제한 / 월 20,000원.
  - 데이터 20GB: 데이터 20GB · 통화 무제한 · 문자 무제한 / 월 28,000원.
  - 카드 내부 Button / Type=Secondary, Size=sm, State=Default / "자세히".
- 신규: 하단 안내 문구
  - "표시된 요금제와 금액은 예시입니다."
  - "요금제 카드를 선택해 상세 페이지로 이동"

### 상태
- 기본: 추천 요금제 카드 3개를 표시한다. 카드의 상태는 State=default다.
- 로딩: 원본에 정의 없음.
- 빈: 원본에 정의 없음.
- 에러: 원본에 정의 없음.

### 이동
- 들어오는 곳:
  - 플로우 시작.
  - 요금제 상세에서 뒤로 가기.
- 나가는 곳:
  - 요금제 카드 클릭 → 선택한 요금제의 상세 화면.

## 02 요금제 상세

### 목적
선택한 요금제의 월 요금과 제공 내역을 확인하고 신청 여부를 결정한다.

### 라우트
/plans/:planId
- 제안 경로

### 구성 요소
- Header / Type=default / 화면 제목 "요금제 상세".
  - 내부 컴포넌트: icon/arrowLeft.
- 신규: 선택한 요금제 제목
  - 표시 예시: "선택한 요금제", "데이터 10GB".
- 신규: 요금 금액 영역
  - "월 20,000원"
  - "부가세 포함 · 월 납부 금액"
- 신규: 제공 내역 섹션 제목
  - "요금제 제공 내역"
- List/Row / Type=default / 제공 내역 3개.
  - 데이터: 월 10GB.
  - 음성 통화: 무제한.
  - 문자: 무제한.
- 신규: 가입 전 확인 영역
  - "가입 전 확인"
  - "선택한 요금제는 신청 폼에서 다시 확인할 수 있어요."
  - "다른 요금제를 보려면 뒤로 가기를 눌러 주세요."
- BottomCTA / Layout=single.
  - 내부 Button / Type=Primary, Size=xl, State=Default / "신청하기".

### 상태
- 기본: 선택한 요금제의 이름, 월 요금, 제공 내역을 표시한다. 완성 화면의 예시는 데이터 10GB 요금제다.
- 로딩: 원본에 정의 없음.
- 빈: 원본에 정의 없음.
- 에러: 원본에 정의 없음.

### 이동
- 들어오는 곳:
  - 요금제 추천 → 요금제 카드 클릭.
- 나가는 곳:
  - 뒤로 가기 → 요금제 추천.
  - "신청하기" 클릭 → 신청 폼 · 개인 정보.

## 03 신청 폼 · 개인 정보

### 목적
요금제 신청에 필요한 신청자의 개인 정보를 입력한다.

### 라우트
/application/personal
- 제안 경로

### 구성 요소
- Header / Type=default / 화면 제목 "신청 폼".
  - 내부 컴포넌트: icon/arrowLeft.
- StepProgress / Step=1 / "1 / 3 · 개인 정보 입력".
- 신규: 신청 단계 라벨
  - "1 개인 정보", "2 요금제 옵션", "3 결제 정보".
- 신규: 개인 정보 입력 안내
  - "개인 정보 입력"
  - "신청자 정보를 입력해 주세요."
- Input / State=filled / 이름.
  - 표시 예시: 홍길동.
- Input / State=filled / 생년월일.
  - 표시 예시: 1995.01.01.
- Input / State=filled / 연락처.
  - 표시 예시: 010-1234-5678.
- Input / State=filled / 이메일.
  - 표시 예시: sample@example.com.
- 신규: 정보 사용 안내 문구
  - "입력 정보는 신청 확인 및 안내에 사용됩니다."
- 신규: 하단 단계 문구
  - "1 / 3 단계"
- BottomCTA / Layout=single.
  - 내부 Button / Type=Primary, Size=xl, State=Default / "다음 · 요금제 옵션 선택".

### 상태
- 기본: 개인 정보 입력 1단계를 표시한다. 완성 화면의 입력 필드 4개는 State=filled다.
- 로딩: 원본에 정의 없음.
- 빈: 미입력 화면 및 안내 방식은 원본에 정의 없음.
- 에러: 유효성 검사 조건 및 오류 문구는 원본에 정의 없음.

### 이동
- 들어오는 곳:
  - 요금제 상세 → "신청하기" 클릭.
  - 입력 정보 확인 → "수정" 클릭 후 신청 폼 재진입.
- 나가는 곳:
  - "다음 · 요금제 옵션 선택" 클릭 → 신청 폼 · 요금제 옵션.
  - 헤더 뒤로 가기의 목적지는 원본 플로우에 명시되지 않음.

## 04 신청 폼 · 요금제 옵션

### 목적
선택한 요금제의 가입 유형과 유심 유형을 선택한다.

### 라우트
/application/options
- 제안 경로

### 구성 요소
- Header / Type=default / 화면 제목 "신청 폼".
  - 내부 컴포넌트: icon/arrowLeft.
- StepProgress / Step=2 / "2 / 3 · 요금제 옵션 선택".
- 신규: 신청 단계 라벨
  - "1 개인 정보", "2 요금제 옵션", "3 결제 정보".
- 신규: 요금제 옵션 선택 안내
  - "요금제 옵션 선택"
  - "선택한 요금제의 가입 옵션을 정해 주세요."
- 신규: 선택 요금제 요약 영역
  - 데이터 10GB.
  - 월 20,000원.
  - 데이터 10GB · 통화 무제한 · 문자 무제한.
- FilterChip / 가입 유형 선택.
  - "번호 이동": State=selected.
  - "신규 가입": State=default.
- FilterChip / 유심 유형 선택.
  - "일반 유심": State=selected.
  - "eSIM": State=default.
- 신규: 선택한 옵션 섹션 제목
  - "선택한 옵션"
- List/Row / Type=default / 선택한 옵션 2개.
  - 가입 유형: 번호 이동.
  - 유심 유형: 일반 유심.
- 신규: 하단 단계 문구
  - "2 / 3 단계"
- BottomCTA / Layout=single.
  - 내부 Button / Type=Primary, Size=xl, State=Default / "다음 · 결제 정보 입력".

### 상태
- 기본: 요금제 옵션 선택 2단계를 표시한다. 완성 화면에서는 번호 이동과 일반 유심이 선택되어 있다.
- 로딩: 원본에 정의 없음.
- 빈: 옵션 미선택 화면은 원본에 정의 없음.
- 에러: 원본에 정의 없음.

### 이동
- 들어오는 곳:
  - 신청 폼 · 개인 정보 → "다음 · 요금제 옵션 선택" 클릭.
- 나가는 곳:
  - "다음 · 결제 정보 입력" 클릭 → 신청 폼 · 결제 정보.
  - 헤더 뒤로 가기의 목적지는 원본 플로우에 명시되지 않음.

## 05 신청 폼 · 결제 정보

### 목적
월 요금을 납부할 결제 정보를 입력한다.

### 라우트
/application/payment
- 제안 경로

### 구성 요소
- Header / Type=default / 화면 제목 "신청 폼".
  - 내부 컴포넌트: icon/arrowLeft.
- StepProgress / Step=3 / "3 / 3 · 결제 정보 입력".
- 신규: 신청 단계 라벨
  - "1 개인 정보", "2 요금제 옵션", "3 결제 정보".
- 신규: 결제 정보 입력 안내
  - "결제 정보 입력"
  - "월 요금을 납부할 정보를 입력해 주세요."
- Input / State=filled / 납부 방법.
  - 표시값: 신용카드.
- Input / State=filled / 카드 명의자.
  - 표시 예시: 홍길동.
- Input / State=filled / 카드 번호.
  - 표시 예시: 1234 5678 **** 1234.
- Input / State=filled / 유효기간.
  - 표시 예시: 12 / 29.
- List/Row / Type=default / 월 납부 금액.
  - 표시 예시: 20,000원.
- 신규: 하단 단계 문구
  - "3 / 3 단계"
- BottomCTA / Layout=single.
  - 내부 Button / Type=Primary, Size=xl, State=Default / "다음 · 입력 정보 확인".

### 상태
- 기본: 결제 정보 입력 3단계를 표시한다. 완성 화면의 입력 필드 4개는 State=filled다.
- 로딩: 원본에 정의 없음.
- 빈: 결제 정보 미입력 화면은 원본에 정의 없음.
- 에러: 결제 정보 검증 조건 및 오류 문구는 원본에 정의 없음.

### 이동
- 들어오는 곳:
  - 신청 폼 · 요금제 옵션 → "다음 · 결제 정보 입력" 클릭.
- 나가는 곳:
  - "다음 · 입력 정보 확인" 클릭 → 입력 정보 확인.
  - 헤더 뒤로 가기의 목적지는 원본 플로우에 명시되지 않음.

## 06 입력 정보 확인

### 목적
입력한 개인 정보, 요금제 옵션, 결제 정보를 확인하고 수정 또는 신청 완료를 선택한다.

### 라우트
/application/review
- 제안 경로

### 구성 요소
- Header / Type=default / 화면 제목 "입력 정보 확인".
  - 내부 컴포넌트: icon/arrowLeft.
- 신규: 신청 내용 확인 안내
  - "신청 내용을 확인해 주세요"
  - "수정이 필요하면 신청 폼으로 돌아갈 수 있어요."
- 신규: 정보 구분 제목
  - "개인 정보", "요금제 및 옵션", "결제 정보".
- List/Row / Type=default / 개인 정보 4개.
  - 이름: 홍길동.
  - 생년월일: 1995.01.01.
  - 연락처: 010-1234-5678.
  - 이메일: sample@example.com.
- List/Row / Type=default / 요금제 및 옵션 3개.
  - 요금제: 데이터 10GB.
  - 가입 유형: 번호 이동.
  - 유심 유형: 일반 유심.
- List/Row / Type=default / 결제 정보 2개.
  - 납부 수단: 신용카드 · 끝 1234.
  - 월 납부 금액: 20,000원.
- BottomCTA / Layout=double.
  - 내부 Button / Type=Secondary, Size=xl, State=Default / "수정".
  - 내부 Button / Type=Primary, Size=xl, State=Default / "신청 완료".

### 상태
- 기본: 앞선 신청 폼에서 입력·선택한 정보를 항목별로 표시한다. 표시값은 완성 화면의 예시다.
- 로딩: 원본에 정의 없음.
- 빈: 원본에 정의 없음.
- 에러: 신청 처리 실패 상태 및 오류 문구는 원본에 정의 없음.

### 이동
- 들어오는 곳:
  - 신청 폼 · 결제 정보 → "다음 · 입력 정보 확인" 클릭.
- 나가는 곳:
  - "수정" 클릭 → 신청 폼으로 돌아가 개인 정보 → 요금제 옵션 → 결제 정보 순서로 진행.
  - "신청 완료" 클릭 → 신청 완료.
  - 헤더 뒤로 가기의 목적지는 원본 플로우에 명시되지 않음.

## 07 신청 완료

### 목적
요금제 신청 완료를 알리고 신청한 내용을 요약해서 보여준다.

### 라우트
/application/complete
- 제안 경로

### 구성 요소
- Header / Type=root / 화면 제목 "신청 완료".
  - 내부 컴포넌트: Logo.
- icon/doneMark / 신청 완료 표시.
  - 내부 컴포넌트: icon/check.
- 신규: 신청 완료 안내
  - "신청 완료"
  - "요금제 신청이 완료되었습니다"
  - "신청하신 내용은 아래와 같습니다."
- 신규: 신청 요약 섹션 제목
  - "신청 요약"
- List/Row / Type=default / 신청 요약 5개.
  - 신청자: 홍길동.
  - 요금제: 데이터 10GB.
  - 가입 유형: 번호 이동.
  - 유심 유형: 일반 유심.
  - 월 납부 금액: 20,000원.
- 신규: 결과 안내 문구
  - "신청 결과는 입력하신 연락처로 안내됩니다."
  - "연락처 010-1234-5678"
- 신규: 하단 종료 문구
  - "신청 절차가 종료되었습니다."

### 상태
- 기본: 신청 완료 표시, 완료 문구, 신청 요약 및 연락처 안내를 표시한다.
- 로딩: 원본에 정의 없음.
- 빈: 원본에 정의 없음.
- 에러: 원본에 정의 없음.

### 이동
- 들어오는 곳:
  - 입력 정보 확인 → "신청 완료" 클릭.
- 나가는 곳:
  - 플로우 종료. 별도 이동 버튼이나 후속 화면은 원본에 없음.
